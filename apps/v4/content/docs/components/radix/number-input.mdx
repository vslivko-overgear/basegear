## API Reference

### NumberInput

Built on `InputGroup`. Arrow up and down change the value by `step`; typed values are clamped to `min` and `max`. All other props go to the input.

| Prop                              | Type                              | Default                     |
| --------------------------------- | --------------------------------- | --------------------------- |
| `value / defaultValue`            | `number \| null`                  | -                           |
| `onValueChange`                   | `(value: number \| null) => void` | -                           |
| `min / max`                       | `number`                          | -                           |
| `step`                            | `number`                          | `1`                         |
| `decrementLabel / incrementLabel` | `string`                          | `"Decrease"` / `"Increase"` |
