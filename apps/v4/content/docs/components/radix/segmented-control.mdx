## Usage

```tsx
import {
  SegmentedControl,
  SegmentedControlCounter,
  SegmentedControlItem,
} from "@/components/ui/segmented-control"
```

```tsx
<SegmentedControl defaultValue="week" aria-label="Period">
  <SegmentedControlItem value="day">Day</SegmentedControlItem>
  <SegmentedControlItem value="week">Week</SegmentedControlItem>
</SegmentedControl>
```

To fill the container, add `w-full` to the control and `flex-1` to the items.

## Icons, Counters and Sizes

Put an icon before the label and a `SegmentedControlCounter` or a `Badge` after it. Use `size="sm"` for a compact control; an item with only an icon needs an `aria-label`.

## API Reference

### SegmentedControl

The root. Built on the Radix radio group: one value is selected.

| Prop                   | Type                | Default     |
| ---------------------- | ------------------- | ----------- |
| `size`                 | `"default" \| "sm"` | `"default"` |
| `value / defaultValue` | `string`            | -           |
| `className`            | `string`            | -           |

### SegmentedControlItem

One option.

| Prop       | Type      | Default |
| ---------- | --------- | ------- |
| `value`    | `string`  | -       |
| `disabled` | `boolean` | `false` |

### SegmentedControlCounter

A number shown after the label.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |
