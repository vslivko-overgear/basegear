## Usage

```tsx
import { Center, Grid, Section, Stack } from "@/components/ui/layout"
```

```tsx
<Stack direction="row" gap={2} align="center">...</Stack>
<Grid columns={3} gap={4}>...</Grid>
```

## API Reference

### Stack

A flex container.

| Prop        | Type                                                      | Default    |
| ----------- | --------------------------------------------------------- | ---------- |
| `direction` | `"column" \| "row"`                                       | `"column"` |
| `gap`       | `number` (spacing steps)                                  | `4`        |
| `align`     | `"start" \| "center" \| "end" \| "stretch" \| "baseline"` | -          |
| `justify`   | `"start" \| "center" \| "end" \| "between" \| "around"`   | -          |
| `wrap`      | `boolean`                                                 | `false`    |

### Grid

A grid with equal columns.

| Prop      | Type                            | Default |
| --------- | ------------------------------- | ------- |
| `columns` | `number \| string` (a template) | `2`     |
| `gap`     | `number` (spacing steps)        | `4`     |

### Center

Centers its content.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### Section

A padded, centered block. Set the width with `max-w-*`.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |
