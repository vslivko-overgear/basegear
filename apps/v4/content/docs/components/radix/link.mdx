## API Reference

### Link

An `a`. Use `asChild` to render a router link.

| Prop        | Type                            | Default   |
| ----------- | ------------------------------- | --------- |
| `underline` | `"hover" \| "always" \| "none"` | `"hover"` |
| `external`  | `boolean`                       | `false`   |
