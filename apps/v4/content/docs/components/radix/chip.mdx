## Chip Group

`ChipGroup` keeps the pressed chips in one value. Pass `variant` or `size` to the group to set it for every chip.

## API Reference

### Chip

A toggle built on the Radix toggle.

| Prop      | Type                                      | Default     |
| --------- | ----------------------------------------- | ----------- |
| `variant` | `"default" \| "success" \| "destructive"` | `"default"` |
| `size`    | `"default" \| "sm"`                       | `"default"` |

### ChipGroup

A group of chips built on the Radix toggle group.

| Prop             | Type      | Default |
| ---------------- | --------- | ------- |
| `variant / size` | as `Chip` | -       |

### ChipCounter

A number after the label.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |
