## Usage

```tsx
import {
  BottomBar,
  BottomBarBadge,
  BottomBarIcon,
  BottomBarItem,
  BottomBarLabel,
} from "@/components/ui/bottom-bar"
```

```tsx
<BottomBar defaultValue="home">
  <BottomBarItem value="home">
    <BottomBarIcon>
      <HomeIcon />
    </BottomBarIcon>
    <BottomBarLabel>Home</BottomBarLabel>
  </BottomBarItem>
</BottomBar>
```

## API Reference

### BottomBar

A `nav`. Keep 2 to 6 items.

| Prop                   | Type                      | Default             |
| ---------------------- | ------------------------- | ------------------- |
| `value / defaultValue` | `string`                  | -                   |
| `onValueChange`        | `(value: string) => void` | -                   |
| `aria-label`           | `string`                  | `"Main navigation"` |

### BottomBarItem

A destination. The active one gets `aria-current="page"` and `data-active`.

| Prop    | Type     | Default |
| ------- | -------- | ------- |
| `value` | `string` | -       |

### BottomBarIcon / BottomBarLabel / BottomBarBadge

The icon, the label under it and a counter on the icon. Without a label, give the item an `aria-label`.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |
