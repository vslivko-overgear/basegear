## Rating Display

`RatingDisplay` shows a score, partial stars included. It is not interactive.

## API Reference

### Rating

Stars the user picks. Whole values only; arrow keys change the value.

| Prop                   | Type                        | Default     |
| ---------------------- | --------------------------- | ----------- |
| `value / defaultValue` | `number`                    | `0`         |
| `onValueChange`        | `(value: number) => void`   | -           |
| `max`                  | `number`                    | `5`         |
| `size`                 | `"default" \| "sm" \| "lg"` | `"default"` |
| `disabled`             | `boolean`                   | `false`     |

### RatingDisplay

A read-only score.

| Prop    | Type                        | Default     |
| ------- | --------------------------- | ----------- |
| `value` | `number`                    | `0`         |
| `max`   | `number`                    | `5`         |
| `size`  | `"default" \| "sm" \| "lg"` | `"default"` |
