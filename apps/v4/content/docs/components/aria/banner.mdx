## Usage

```tsx
import {
  Banner,
  BannerClose,
  BannerDescription,
  BannerTitle,
} from "@/components/ui/banner"
```

```tsx
<Banner variant="success">
  <CircleCheckIcon />
  <BannerTitle>Payment received</BannerTitle>
  <BannerDescription>The booster will start soon.</BannerDescription>
  <BannerClose onClick={dismiss} />
</Banner>
```

## Variants

`info` and `success` are announced politely (`role="status"`), `warning` and `destructive` as alerts (`role="alert"`).

## API Reference

### Banner

The root. An icon as the first child is placed in its own column.

| Prop        | Type                                                | Default  |
| ----------- | --------------------------------------------------- | -------- |
| `variant`   | `"info" \| "success" \| "warning" \| "destructive"` | `"info"` |
| `className` | `string`                                            | -        |

### BannerClose

A close button in the corner. Renders an X icon unless you pass children.

| Prop         | Type     | Default   |
| ------------ | -------- | --------- |
| `aria-label` | `string` | `"Close"` |
