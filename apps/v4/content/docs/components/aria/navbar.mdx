## Usage

```tsx
import {
  Navbar,
  NavbarEnd,
  NavbarHeading,
  NavbarStart,
  NavbarSubtitle,
  NavbarTitle,
} from "@/components/ui/navbar"
```

```tsx
<Navbar>
  <NavbarStart>
    <Button variant="ghost" size="icon" aria-label="Back">
      <ChevronLeftIcon />
    </Button>
  </NavbarStart>
  <NavbarHeading>
    <NavbarTitle>Order #4821</NavbarTitle>
    <NavbarSubtitle>Mythic+ Dungeon Boost</NavbarSubtitle>
  </NavbarHeading>
  <NavbarEnd />
</Navbar>
```

## API Reference

### Navbar

A three-column grid: the heading stays centered whatever is on the sides.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### NavbarStart / NavbarHeading / NavbarEnd

The left side, the centered heading and the right side.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### NavbarTitle / NavbarSubtitle

The title (`h1`) and a second line; both truncate.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |
