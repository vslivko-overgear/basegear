## Usage

```tsx
import {
  Status,
  StatusActions,
  StatusDescription,
  StatusMedia,
  StatusTitle,
} from "@/components/ui/status"
```

```tsx
<Status variant="success">
  <StatusMedia>
    <CircleCheckIcon />
  </StatusMedia>
  <StatusTitle>All done</StatusTitle>
  <StatusDescription>The order is completed.</StatusDescription>
</Status>
```

## Variants

The `variant` sets the color of the media circle.

## API Reference

### Status

The root.

| Prop        | Type                                                             | Default     |
| ----------- | ---------------------------------------------------------------- | ----------- |
| `variant`   | `"default" \| "info" \| "success" \| "warning" \| "destructive"` | `"default"` |
| `className` | `string`                                                         | -           |

### StatusMedia

The circle with the icon.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### StatusTitle / StatusDescription / StatusActions

Title, text and a row of actions.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |
